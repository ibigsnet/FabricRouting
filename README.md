**FRR (FRRouting)**

Optional FRRouting suite for Unraid — **fully automated** install (like the Nvidia Driver plugin): the plugin downloads, verifies, and installs FRR for your Unraid version. Choose daemons under **Settings → FRR**. Standalone: Thunderbolt Net is not required. Does not edit eth0/br0 or Unraid Network Settings by default. Pair with Thunderbolt Net for TB multi-host OpenFabric.
