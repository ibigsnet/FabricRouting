**FRR (FRRouting)**

Optional FRRouting suite for Unraid — install packages from the flash, enable **zebra** / OpenFabric **fabricd** (and other daemons if you choose), and manage them under **Settings → FRR**. Standalone: Thunderbolt Net is not required. Idle and safe when no packages are present. Does not edit eth0/br0 or Unraid Network Settings by default. Pair with Thunderbolt Net for TB multi-host OpenFabric.
