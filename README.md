**Fabric Routing (FRR)**

Optional FRRouting packages for Unraid — **fully automated** install (like the Nvidia Driver plugin): downloads and installs FRR matched to your **Unraid product version** + arch (`zebra`, OpenFabric/`fabricd`, optional OSPF/BGP, …). UI: **Settings → Network Settings → Fabric Routing** (next to stock Routing Table). Standalone: Thunderbolt Net is not required. Does not edit eth0/br0 by default. Pair with Thunderbolt Net for TB multi-host OpenFabric (policy there; packages here).
