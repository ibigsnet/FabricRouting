**Fabric Routing (FRR)**

Optional FRRouting packages and daemons for Unraid (zebra, fabricd/OpenFabric, optional OSPF/BGP, and more). Install packages from Settings → Network Settings → Fabric Routing. Does not change eth0/br0 by default.
