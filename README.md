**FRR (FRRouting)**

Optional FRRouting suite for Unraid — **fully automated** install (like the Nvidia Driver plugin): downloads and installs FRR packages matched to your **Unraid product version** + arch. Choose daemons under **Settings → FRR**. Standalone: Thunderbolt Net is not required. Does not edit eth0/br0 by default. Pair with Thunderbolt Net for TB multi-host OpenFabric (policy there; packages here).
