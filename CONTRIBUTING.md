# Contributing

Bug reports, docs fixes, package catalog help, and pull requests are welcome.

1. Open an [issue](https://github.com/ibigsnet/FabricRouting/issues) for discussion when the change is large.
2. Prefer focused PRs against `main`.
3. Include Unraid **product version** and **arch** with package or install bugs.
4. This plugin must stay usable **without** Thunderbolt Net (no hard dependency on its PHP).

Support: the [Thunderbolt Net forum thread](https://forums.unraid.net/topic/200065-plugin-thunderbolt-net-host-to-host-networking-over-thunderbolt-345-and-usb44v2/) (shared until Fabric Routing has its own) and [GitHub Issues](https://github.com/ibigsnet/FabricRouting/issues).
